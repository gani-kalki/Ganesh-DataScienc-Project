Data Science Experiments

Explore practical experiments designed to develop your skills in data preparation, visualization, and time-based data analysis using Python and its popular data science libraries.

EXPERIMENT 04

Data Wrangling

This experiment focuses on transforming raw data into a clean, organized, and meaningful format suitable for analysis. Students learn how to handle missing values, remove duplicate records, correct data types, and identify inconsistent data using Python Pandas. It also covers filtering, sorting, grouping, merging, and reshaping datasets. These techniques improve data quality and prepare information for further analysis and visualization.

Key Topics

  • Data cleaning and preprocessing using Pandas
  • Handling missing values and duplicate records
  • Data type conversion and inconsistent data treatment
  • Filtering, sorting, and grouping datasets
  • Merging and reshaping data
EXPERIMENT 05

Data Visualization with Matplotlib and Seaborn

This experiment introduces graphical techniques for understanding patterns, trends, distributions, and relationships in data. Students learn to create informative charts using Matplotlib and Seaborn. Matplotlib supports detailed customization of plots, while Seaborn provides convenient tools for statistical visualization. Students practice selecting suitable charts, adding labels and legends, and presenting analytical results clearly.

Key Topics

  • Introduction to Matplotlib and Seaborn
  • Line charts, bar charts, and scatter plots
  • Histograms and distribution plots
  • Box plots, violin plots, and heatmaps
  • Plot titles, labels, legends, and customization
EXPERIMENT 06

Time Series Analysis

This experiment focuses on working with data recorded over time. Students learn to create date ranges, use datetime indexes, manage time zones, and convert between timestamps and periods using Python Pandas. It also covers frequency conversion, resampling, and aggregation of time-series data. These methods help organize chronological datasets and understand changes over time. Time series techniques are useful in weather monitoring, sales analysis, financial data, and sensor monitoring applications.

Key Topics

  • Creating and working with DatetimeIndex
  • Generating date ranges using date_range()
  • Time zone localization and conversion
  • Period arithmetic and period_range()
  • Changing frequency using asfreq()
  • Converting timestamps using to_period()
  • Resampling and aggregating time-series data
