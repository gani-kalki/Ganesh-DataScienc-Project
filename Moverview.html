Data Science Laboratory Modules

Explore the five modules of the Data Science Laboratory. Each module introduces important concepts, techniques, and methods used to understand, process, analyze, and interpret data.

MODULE 01

Introduction to Data Science

This module introduces the fundamental concepts of Data Science and its role in extracting useful information from data. It explains the data science lifecycle, different types of data, data collection, data preprocessing, and the skills required by a data scientist. Students learn how data analysis supports decision-making and how descriptive, diagnostic, predictive, and prescriptive analytics are used to solve real-world problems.

Key Topics

  • Definition, scope, and applications of Data Science
  • Data types and data collections
  • Data preprocessing and cleaning
  • Types of data analytics
MODULE 02

Data Extraction and Feature Selection

This module focuses on preparing datasets for effective analysis and machine learning. Students learn how to extract relevant information, identify useful features, and reduce unnecessary or redundant attributes. It introduces feature selection approaches, including filter and wrapper methods, and explains concepts such as entropy, decision trees, and random forests as tools for evaluating features and building predictive models.

Key Topics

  • Data extraction and feature selection
  • Filter and wrapper methods
  • Entropy and information gain
  • Introduction to decision trees and random forests
MODULE 03

Feature Selection and Decision Tree Foundations

This module explores how to identify the most informative attributes in a dataset and use them to construct decision trees. Students study feature relevance, splitting criteria, entropy, information gain, and the Gini index. The module explains how decision trees divide data into smaller groups to make predictions and how tree depth, pruning, and feature selection affect model complexity and predictive performance.

Key Topics

  • Feature relevance and selection criteria
  • Decision tree construction
  • Entropy, information gain, and Gini index
  • Tree pruning and model evaluation
MODULE 04

Ensemble Learning

This module introduces ensemble learning, a machine learning approach that combines multiple models to improve prediction quality. Students explore how combining the outputs of different learners can improve accuracy, stability, and generalization. The module covers bagging, boosting, and random forests, highlighting their working principles, advantages, limitations, and applications in classification and prediction tasks.

Key Topics

  • Fundamentals of ensemble learning
  • Bagging and boosting techniques
  • Random forest algorithm
  • Advantages and applications of ensembles
MODULE 05

Dimensionality Reduction

This module explains techniques for reducing the number of features in high-dimensional datasets while preserving important information. Students learn why high dimensionality can increase computational cost and make analysis more difficult. The module introduces Principal Component Analysis (PCA) and Singular Value Decomposition (SVD), explaining how these techniques transform data into a smaller representation that can support visualization, efficient computation, and machine learning.

Key Topics

  • Curse of dimensionality
  • Dimensionality reduction concepts
  • Principal Component Analysis (PCA)
  • Singular Value Decomposition (SVD)
